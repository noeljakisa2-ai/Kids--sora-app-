# Village Hero: Wildwood

An original, mobile-friendly top-down/isometric-inspired action RPG prototype built with plain HTML, CSS, Canvas, and JavaScript.

## Play
Open `index.html` in a modern browser. No build step, packages, API keys, or paid services are required.

## Controls
- Android/mobile: left joystick to move; **ATTACK** to swing; **TALK** when near a villager.
- Keyboard: WASD or arrow keys to move; Space to attack.

## Current prototype features
- Small village with houses, paths, trees, and named villagers
- Monster slimes that follow the player and deal damage
- Sword attacks, health, XP orbs, coins, level progression
- Responsive mobile touch controls and keyboard controls

## Scope and status
This is an original prototype inspired by broad action-RPG conventions. It does not contain XP Hero's proprietary source code, art, maps, or other extracted assets. No live deployment or on-device testing is claimed yet.
